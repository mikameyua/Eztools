## M 项（面板 · W5-b）

### M1 ★ 直贴端到端（还原前台 + Ctrl+V 注入）

探针把 Ctrl+V 真注入抑制了（贴进运行探针的终端不可接受），所以这一环只能手工：

1. 在记事本/编辑器里把光标放到任意位置。
2. 复制几段文字（含一段中文、一段英文）。
3. `Eztools.Desktop.exe --probe-clip-panel` 先造点历史，或直接运行托盘（W5-c 后用热键 Ctrl+Alt+V）唤出面板。
4. 选中一条 → **Enter**。
5. **判据**：面板收起；内容出现在原窗口的光标处（不是剪贴板里等你手动 Ctrl+V）。
6. 反向：直贴前把原窗口关掉再 Enter → 判据 = 面板收起 + 托盘气泡"已复制，但未能还原原窗口"（降级路径可见，不静默）。

### M2 ★ 键盘全链路（真人按键，覆盖探针摸不到的消息层）

面板唤出后逐项手测（判据见括号）。**Del / Ctrl+P / Ctrl+C 无需先选中——无选中即作用于第一条**（2026-09-27 修复：原实现无选中时静默不动作，被感知为"快捷键没实现"）；置顶/删除都有状态行回显。

- 打字（**英文/大写锁**）→ 搜索实时过滤（防抖 30ms）。✅ 2026-09-27 已自动化验证（LL 钩子供字，hello 逐键精确）。
  ⚠️ **已知限制**：面板内字母被 LL 钩子吃掉 = **打不了中文**（中文搜索走 `ezt clip search 中文词`）；面板内中/英切换钮 = W5-d 候选。
- ↓/↑ 移动高亮（焦点不掉进列表，继续打字仍进搜索框）。
- Enter 直贴选中项；无选中项时 Enter 直贴第一条。
- Ctrl+Enter 仅复制（面板**不**收起，状态行回显"已复制（未直贴）"）。
- Del 删除选中条目（列表即时少一行）。
- Ctrl+P 置顶/取消（📌 标记切换，置顶条目排到最前）。
- Ctrl+C 复制选中内容（面板不收起）。
- Esc / X / Alt+F4 / 点外面 → 全部只是收起；**再次热键/探针唤出必须可用**（§2.25① 契约）。

### M3 图片缩略图（图片条目端到端归 W5-c 监听层，先手工造库）

1. `ezt clip status` 记住库路径（`<config-root>/data/clip/`）。
2. 手工放一张 PNG 到 `images/`，用 `ezt clip pin/copy` 无法造条目 → 临时用 selftest 同款 API 或等 W5-c；
   （W5-c 起改为：截屏 → 复制图片 → 打开面板 → 判据 = 48px 缩略图显示、行高不塌、
   滚动 200 条不卡（虚拟化）+ Enter 直贴图片到画图/聊天窗口。）
