## 2. 手工项（无法自动化的部分）

### M1 真机应用启动与定位（动作真的会起进程，探针不真起）

- **步骤**：`Ctrl+Alt+S` 唤出搜索窗（搜索热键，配置键 `search.hotkey`；★ 不是 Ctrl+Alt+O —— 那是屏幕取字 OCR）→ 输入一个真实存在的应用（如 `code` / `记事本`）→ **Enter** 启动。
- **判据**：
  - 应用启动成功；工作目录正确（便携版应用能找到自身资源）；
  - **Ctrl+Enter** 走次动作 ⇒ 资源管理器定位并**选中**该快捷方式/exe（只包路径的引号语义）；
  - 启动过的应用，下次相同查询时**排序提前**（频次记忆生效的可感知面）。
- **副作用须知**：本项会真实启动应用/资源管理器窗口，测完自行关闭。

```bash
cd "D:/01-项目代码/Eztools" && DOTNET_ROOT=D:/dotnet10 ./src/Eztools.Desktop/bin/Debug/net10.0-windows10.0.19041.0/Eztools.Desktop.exe
```

```powershell
Set-Location 'D:\01-项目代码\Eztools'; $env:DOTNET_ROOT = 'D:\dotnet10'
& '.\src\Eztools.Desktop\bin\Debug\net10.0-windows10.0.19041.0\Eztools.Desktop.exe'
```

### M2 中文输入法真机输入（W3 手工 M2 的 W7 抽查）

- **步骤**：开中文输入法（微软拼音默认配置）→ 唤出搜索窗 → 输入 `baobia`（候选上屏"报表"类词）→ 再输入英文 `code`。
- **判据**：
  - 上屏后结果列表随文本刷新（拼音组合窗口期间不误触发查询命令）；
  - 英文直通字符不进框的修复**未回归**（`RestoreImeAssociation` 行为不变）；
  - apps 中文标题（如 `记事本`）可被中文查询命中（`报` 命中 `报表工具` 同族的子序列语义）。

### M3 别名（给应用起小名，中文词也能搜到英文名应用）

- **背景**：搜索匹配的是**条目文件名**里的字符（开始菜单里看到的"记事本"中文名来自 shell 解析，v1 搜索拿不到），所以搜"记事本"找不到 `Notepad`、搜"雷神"找不到 `leigod.exe`。别名 = 自己配映射：**等号左边 = 你想输入的词，右边 = 该应用条目标题或路径里真实存在的连续一段**。
- **★ 方向别配反（10-02 实机教训）**：`记事本=notepad` = 输入"记事本"找到 Notepad ✔；`note=notepad` = 输入 note 找 Notepad（打 notepad 本来就能搜到，没意义）。想用中文搜，**别名就写中文**。
- **★ 目标怎么写（关键）**：`别名=目标` 里的**目标必须是应用条目标题或路径里真实存在的连续一段**（不区分大小写、不必整串）。系统里的条目是**文件名**（如 `notepad.exe`、`leigod.exe`），不是它的中文名 —— 写"记事本""雷声加速器"是命中不了的。**先搜一次应用，抄它结果行/副行里的字符串**；目标尽量写长一点防误伤。
- **步骤**：
  1. 跑下面这条命令（`记事本`/`雷神`/`雷神加速器` → 各自应用，目标取自条目标题/路径里的真实片段）；
  2. **★ 重启托盘**（托盘图标右键 → 退出 → 重新打开 exe）—— 别名在搜索窗创建时读一次，改完不重启不生效（已知缺口，见下）；
  3. 按 `Ctrl+Alt+S` 唤出搜索窗 → 输入 `记事本` ⇒ `Notepad` 出现在结果里且排第一 = 通过；
  4. 输入 `雷神` 或 `雷神加速器` ⇒ `leigod.exe` 同理 = 通过；
  5. （可选）打开设置窗口（托盘右键 → 设置），能看到"启动器应用别名"输入框里是刚设的值。
- **收尾**：跑清尾命令删掉这两个别名（设置会恢复原样）。
- **★ 已知缺口（W8 候选）**：别名 / 频次开关改完需要重启托盘才生效（运行中的搜索窗不会重读配置）。
- **★ 10-02 已修**：旧版托盘**每次退出都会无条件重写一次 usage.json**（哪怕关闭期间零记录），
  会把 mtime 推到"重启托盘的时刻"，让 M4 第 6 步永远对不上 —— 已加脏闸修复（踩坑全集 §2.39，
  selftest 36.11 钉住）。修复后按上述步骤跑即可通过。

```bash
cd "D:/01-项目代码/Eztools" && ./src/Eztools.Cli/bin/Debug/net10.0-windows10.0.19041.0/ezt.exe config set desktop launcher.alias "记事本=notepad;雷神=leigod;雷神加速器=leigod"
# 测完收尾（删掉这些别名）
./src/Eztools.Cli/bin/Debug/net10.0-windows10.0.19041.0/ezt.exe config unset desktop launcher.alias
```

```powershell
Set-Location 'D:\01-项目代码\Eztools'
& '.\src\Eztools.Cli\bin\Debug\net10.0-windows10.0.19041.0\ezt.exe' config set desktop launcher.alias '记事本=notepad;雷神=leigod;雷神加速器=leigod'
# 测完收尾（删掉这些别名）
& '.\src\Eztools.Cli\bin\Debug\net10.0-windows10.0.19041.0\ezt.exe' config unset desktop launcher.alias
```

### M4 频次记忆的开关（验证"关掉就一个字都不记，且以前记的不丢"）

> **★ 可裁剪（2026-10-02 拍板）**：M4 的核心判据（关闭期间零记录、退出 flush 不碰文件、
> 落盘回读一致）已被 selftest **36.3 / 36.11**（含突变验证）机器钉住，且 10-02 实机就是它
> 抓出了"退出 flush 无条件重写"的真 bug（踩坑全集 §2.39，已修）—— 手工重跑边际价值低，
> 时间紧可跳过，平时使用中顺手观察即可。

- **目的**：设置里有个"启动器频次记忆"开关。它关闭后，系统应该**完全不记录**你启动过什么；重新打开后，以前记的应该**原样还在**。
- **步骤**：
  1. 先正常用一次：`Ctrl+Alt+S` → 输入 `code` → Enter 启动 vscode（让系统先记上数据）；
  2. 打开文件管理器，地址栏粘贴 `%APPDATA%\Eztools\launcher` 回车 ⇒ 看到 `usage.json`，右键 → 属性，**记下"修改时间"**；
  3. 跑下面的"关闭"命令；
  4. **★ 重启托盘**（托盘右键退出 → 重新打开 exe）—— 开关在搜索窗创建时读一次，不重启不生效（同 M3 的已知缺口）；
  5. 再搜索并启动两三个应用（记事本、vscode 都行）；
  6. 再看 `usage.json` 的修改时间 ⇒ **和第 2 步一模一样 = 通过**（关闭期间系统碰都没碰它）；
  7. 跑下面的"打开"命令 → **再重启一次托盘** → 启动一个应用 ⇒ 修改时间变新了，用记事本打开 `usage.json` 能看到之前的条目还在、次数在涨 = 通过。
- **命令**：

```bash
# 关闭
cd "D:/01-项目代码/Eztools" && ./src/Eztools.Cli/bin/Debug/net10.0-windows10.0.19041.0/ezt.exe config set desktop launcher.usage false
# 打开（测完恢复）
./src/Eztools.Cli/bin/Debug/net10.0-windows10.0.19041.0/ezt.exe config set desktop launcher.usage true
```

### M5 搜索窗的基本手感（开关与聚焦）

- **目的**：确认搜索窗"开-关-打字"这些基本行为没坏。每条单独测，通过打勾即可：
  1. 按 `Ctrl+Alt+S` 唤出 → 按 **Esc** ⇒ 窗口消失；
  2. 再唤出 → **鼠标点一下窗口外面**任意位置 ⇒ 窗口消失；
  3. 再唤出 → **Alt+Tab** 切到别的程序 ⇒ 窗口自己收掉；
  4. 快速**连按两三次** `Ctrl+Alt+S` ⇒ 桌面上始终只有一个搜索窗，不会叠出好几个；
  5. 每次唤出后**不碰鼠标直接打字** ⇒ 字直接进输入框（光标自动就在里面），结果列表跟着刷新。

（中文输入法下的表现单独算 M2，见上。）

### M6 结果行的图标（好不好看、缺了会不会坏事）

- **目的**：应用结果左边的图标显示正常；图标万一取不到，也不影响搜索和启动。
- **步骤**：
  1. `Ctrl+Alt+S` → 输入 `code` ⇒ 结果行左边有 vscode 图标，大小和文字协调、不模糊（显示缩放 125%/150% 下也检查一眼）= 通过；
  2. 找一个网页快捷方式（开始菜单里 `.url` 类型，比如某些软件的官网入口）搜一下 ⇒ 也有图标 = 通过；
  3. （兜底项，碰不到可跳过）如果哪天看到某行**没有图标**：它应该仍然能搜到、能 Enter 启动 —— 图标只是装饰，缺了不碍事 = 正常设计。
