## 1. 功能概述

**一句话**：后台常驻监听系统剪贴板 → 文本 / HTML / 图片自动入 SQLite 库 → 全局热键唤出历史面板 → 搜索 / Pin / 管理 → **回车直贴回原窗口**。

- **产品定位**：Eztools「唤出式工具」家族第三员（快搜窗、屏幕取字之后）。V1 范围 = **历史管理器**。
- **设计哲学对齐**：给"复制"这个零成本动作加一层"零成本回放"。任何增加操作成本或认知负担的功能都是负资产（§2.3 非目标全部由此推导）。单职责窗口、快进快出、零特权（不碰 Core）、全离线。
- **核心体验差异化**（相对 Win+V）：持久化不丢 + 中文搜索 + 直贴闭环 + 隐私排除。Eztools 独有协同：图片条目可调用 **W4 OCR 引擎提取文字**（零新增引擎成本）。
- **外部参考收敛为三条**（2026-09-26 已拍板裁剪）：
  1. **EcoPaste**（Apache-2.0，Rust/Tauri）——只借鉴架构思路：SQLite+FTS5 搜索、上限/保留期配置、敏感内容跳过模式。**语言不通，零代码照搬**。
  2. **Rememory**（MIT，C#/WinUI 3）——.NET 参考实现：app-filtering（按来源进程过滤）思路可抄，MIT 许可。
  3. **PowerToys AdvancedPaste**（MIT，本地 fork `PowerToys/src/modules/AdvancedPaste/AdvancedPaste/`）——**V1 不用，V2 转换引擎的代码银行**（`TransformHelpers` / `HtmlToTextHelper` / `MarkdownHelper`）。注意其依赖 WinRT `DataPackage`，移植需剥离。
- **许可修正（2026-09-26 敲定时发现）**：Eztools 自身是 **GPL-3.0-or-later**（`LICENSE` + D7 决策），调研报告中"Ditto/CopyQ 禁抄"的结论**对本项目过严**——GPL-3.0 源码与本项目许可兼容，可以借用。但纪律不变：**任何外部借用先登记 `参考来源.md`**；同等条件下仍优先 MIT 源（更干净，且 PowerToys 源码就在本地）。
- **已裁剪的非目标**：跨设备/云同步（永久排除）、AI 改写（永久排除）、分类标签、多标签页、脚本引擎、富文本编辑（详见 §2.3，勿在实施时复活）。

## 2. 需求说明

### 2.1 功能需求（FR）

| # | 需求 | 验收口径 |
|---|------|----------|
| FR-1 | **后台监听自动入库**：文本 / HTML（存纯文本+标记）/ 图片（PNG 落盘）；文件路径列表记为 `FileList` 条目（加分项） | 探针 `--probe-clip-monitor`：程序化写剪贴板 → 断言库内条目 |
| FR-2 | **持久化**：SQLite 单文件库，重启不丢 | 杀进程重启 → 断言条目仍在 |
| FR-3 | **去重合并**：内容 SHA-256 指纹，重复复制 → 置顶 + `copy_count+1` + 刷新 `last_used_at` | 探针两次写同内容 → 断言 1 条 count=2 |
| FR-4 | **上限清理**：超 `max-items` 删最旧（pinned 豁免）；图片按 `image-retention-days` 过期回收 | CLI 构造超限 → 断言守恒：`删除数 = 总数-上限` 且 pinned 全存活 |
| FR-5 | **全局热键唤出面板**，默认 `Ctrl+Alt+V`（避开 Win+V / Win+Shift+V / Alt+V 菜单加速键），desktop.json 可配；仲裁失败 → 气泡（复用 W4-c 链） | verify-desktop 热键行 + 探针真注入 |
| FR-6 | **面板列表**：虚拟化 + 文本摘要预览 + 图片缩略图（**懒生成**，不随入库同步生成）+ 类型过滤（全部/文本/图片/文件） | 手工清单 + 复用 W3-d 虚拟化断言模式 |
| FR-7 | **中文模糊搜索**：FTS5 `tokenize='trigram'`；**≥3 字符走 FTS，<3 字符走 LIKE 兜底**（trigram 硬限制）；输入防抖 30ms（对齐快搜） | selftest：两字词/三字词/中英混合三档断言 |
| FR-8 | **Pin/Unpin**：置顶区显示，不被任何清理删除 | CLI pin → clear → 断言存活 |
| FR-9 | **条目管理**：单条删除 / 一键清空（pinned 豁免，可关）/ 重新复制 / **粘贴为纯文本**（重制纯文本并直贴，`Clipboard.SetText` 级实现，不动用 V2 引擎） | CLI + 手工 |
| FR-10 | **直贴闭环**：`Enter` = 内容写剪贴板 → Hide 面板 → 还原唤出前前台窗口 → 注入 Ctrl+V；`Ctrl+Enter` = 仅复制不粘贴。直贴失败降级为"仅复制"+气泡 | 探针 `--probe-clip-panel`（真键注入，参考 `--probe-search-summon`） |
| FR-11 | **隐私排除**：① 应用黑名单（`GetClipboardOwner`→PID→进程名比对，命中不入库）；② 临时暂停捕获（托盘 toggle，气泡确认状态）；③ 提权进程内容（UIPI 读不到）→ 只记**占位条目**"[提权进程 ××× 复制的内容未保存]"，不存内容 | 手工清单 M 项：密码管理器复制 → 断言库内无该内容（**隐私断言必须是"内容不存在"**，不是"功能正常"） |
| FR-12 | **托盘**：打开面板 / 暂停捕获 toggle / 清空历史 / 设置入口 | verify-desktop 菜单断言 |
| FR-13 | **CLI**：`ezt clip list [--kind] [--limit]` / `search <kw>` / `pin|unpin <id>` / `delete <id>` / `clear [--keep-pinned]` / `status`（监听状态/条数/库大小） | 断言落退出码 + stdout 数字 |
| FR-14 | **设置项**（desktop.json 伪工具节接 P1a，schema 放 Host 层——W4-c 铁律）：`clip.enabled` / `clip.hotkey` / `clip.max-items`(默认 1000，100~50000) / `clip.image-retention-days`(默认 30) / `clip.blacklist`(默认空) | `--probe-host-settings` 模式复刻 |
| FR-15 | **图片 OCR 提字**（Eztools 差异化）：图片条目右键"提取文字"→ 调 W4 引擎 → 结果进剪贴板 | W5-d，探针复用 OCR 探针模式 |

### 2.2 非功能需求（NFR）

- **NFR-1 全离线**：V1 任何路径不发起网络请求；AI 相关永久排除（剪贴板是最隐私的表面，送云自相矛盾）。
- **NFR-2 零特权**：监听在 Desktop 托盘常驻进程（本就有消息循环）；代码永不进入 Eztools.Core。提权内容按 FR-11③ 降级，不为它提权。
- **NFR-3 依赖最小化**：新增 NuGet 仅两个——`Microsoft.Data.Sqlite`（微软官方，MIT）+ `Clowd.Clipboard.Wpf`（MIT，读写+DIB 解析）。**禁引** EventHook / 全局钩子库（`AddClipboardFormatListener` 消息驱动 30 行 P/Invoke 足够）。两者登记 `THIRD-PARTY-NOTICES.md` + `参考来源.md`。
- **NFR-4 性能**：入库 <10ms（文本）/ <100ms（图片）；面板唤出 ≤150ms（对齐快搜 G2 精神）；搜索 p95 ≤30ms @1 万条。
- **NFR-5 资源**：消息驱动 CPU≈0（禁止轮询剪贴板）；面板空闲内存增量 ≤50MB（缩略图懒生成 + 虚拟化）；库+图片总量默认软上限 500MB（status 可见）。

### 2.3 非目标（Non-goals，v1 明确不做）

| 不做 | 理由 | 复活条件 |
|------|------|----------|
| 跨设备 / 云同步 | 隐私悖论（手机密码自动到电脑）+ 工程量超工具本体 + 动摇单机定位 | **永久排除**（除非推翻产品定位） |
| AI 改写 / 云 AI | 违反 NFR-1；剪贴板隐私敏感性与云上传矛盾 | **永久排除** |
| 分类 / 标签 / 笔记 | 违背零成本捕获——没人复制时停下来分类 | 类型过滤+Pin 实测覆盖不了 |
| 多标签页 / 工作区 | 认知负担，把一步变两步（CopyQ 反例） | — |
| 脚本引擎 / 插件系统 | 维护成本巨大；Eztools 自身就是工具集 | — |
| 富文本编辑 | 角色错位，编辑是编辑器的事 | — |
| RTF / 自定义格式原生保真 | 降级存纯文本预览 | 高频需求出现 |
| 格式转换全家桶（Markdown/JSON/存文件/AI） | AdvancedPaste 引擎移植，**V2 backlog** | 用户拍板 |
| 敏感内容正则自动跳过（私钥/Token/JWT） | 应用黑名单+暂停已覆盖主场景；正则是第二道保险，**backlog P3** | 黑名单实测不够用 |
| 多选合并粘贴 / 片段模板变量 | backlog P2/P3，等 Pin 使用数据 | — |

## 3. 整体架构

### 3.1 进程与项目落位

```
Eztools.Desktop（现有宿主：托盘 + 快搜窗 + OCR 遮罩，同进程模型不变）
 ├─ ClipboardMonitor（新增：HwndSource 挂 AddClipboardFormatListener / WM_CLIPBOARDUPDATE）
 ├─ ClipboardHistoryPanel（新增唤出窗，与 SearchWindow 同层，复用其骨架）
 └─ 引用 Eztools.Clipboard

Eztools.Clipboard（新增类库，TFM net10.0-windows）
 ├─ HistoryStore（SQLite+FTS5：CRUD / 去重 / 上限清理 / 搜索 / 迁移）
 ├─ CaptureService（格式识别 text/html/image/filelist；Clowd.Clipboard 读写；DIB→PNG 落盘）
 ├─ PrivacyFilter（黑名单进程匹配 / 暂停 flag / UIPI 降级判定）
 └─ PasteBack（还原前台 + 注入 Ctrl+V + 失败降级）

Eztools.Cli（现有）
 └─ `ezt clip …` 子命令（引用 Eztools.Clipboard）
```

**落位原则**：UI 归 Desktop、原语归 Clipboard 类库、脚本入口归 Cli；不新建进程，不动 Eztools.Core。

### 3.2 捕获数据流（消息驱动，全程无轮询）

```
系统剪贴板变化 → WM_CLIPBOARDUPDATE（HwndSource 钩子）
  → PrivacyFilter：暂停 flag？黑名单进程？→ 命中：丢弃（日志 Debug 级，不静默不惊扰）
  → CaptureService：读格式（优先级 Text > Html > Image > FileList）
      提权内容读不到 → 占位条目（FR-11③）
  → 计算 SHA-256 → HistoryStore.Upsert（命中 hash：置顶+计数；否则插入+超限清理）
  → 图片：PNG 落 config-root/data/clip/images/<hash前16>.png，DB 存相对路径
  → 面板若存活 → 轻量刷新通知
```

### 3.3 面板 / 直贴数据流

```
Ctrl+Alt+V → HotkeyHook（现有）→ Panel 常驻隐藏窗 Show+抢前台
  （复用 §2.24：AttachThreadInput 组合拳 + _summoning 屏蔽瞬态失焦）
  → 输入焦点常驻搜索框（快搜同款）→ 记录唤出前 GetForegroundWindow() 句柄
  → 列表/搜索/预览（W3-d 虚拟化模板三重前提 + 键盘链 §2.26）
  → Enter：内容写剪贴板 → Hide → 还原原窗前台 → PasteBack 注入 Ctrl+V
  → Ctrl+Enter：仅复制 → Hide
  → X / Esc：Hide（Closing 拦截，§2.25①，禁真关闭）
```

### 3.4 SQLite schema（设计基准，实施微调需回填本文）

```sql
CREATE TABLE clips (
  id           INTEGER PRIMARY KEY AUTOINCREMENT,
  kind         INTEGER NOT NULL,              -- 0=Text 1=Image 2=FileList
  content      TEXT,                          -- 文本全文 / 文件路径列表（换行分隔）
  preview      TEXT NOT NULL,                 -- 列表摘要 ≤200 字符（入库时生成，读路径不加工）
  image_path   TEXT,                          -- kind=1：相对路径（相对 data/clip/）
  image_bytes  INTEGER,
  hash         TEXT NOT NULL,                 -- SHA-256 内容指纹（去重键）
  source_app   TEXT,                          -- 来源进程名（审计+黑名单命中显示）
  pinned       INTEGER NOT NULL DEFAULT 0,
  copy_count   INTEGER NOT NULL DEFAULT 1,
  created_at   TEXT NOT NULL,                 -- ISO8601 本地时间
  last_used_at TEXT NOT NULL
);
CREATE INDEX idx_clips_used ON clips(pinned DESC, last_used_at DESC);
CREATE VIRTUAL TABLE clips_fts USING fts5(
  content, content='clips', content_rowid='id', tokenize='trigram'
);  -- 外部内容表 + AI/AU/AD 三触发器同步
```

- 去 key：`hash` 唯一性用 Upsert 语义而非 UNIQUE 约束（pinned 条目重复复制要刷新计数而非拒绝）。
- 迁移：库头记 `schema_version`，起步即 v1，防后续加列踩"ALTER 静默失败"类坑。

## 5. 核心业务流程

### 5.1 捕获主流程

1. 复制发生（任意应用）→ `WM_CLIPBOARDUPDATE`。
2. `PrivacyFilter` 判定：暂停中 / 黑名单 → 静默丢弃；提权进程 → 占位条目。
3. `CaptureService` 读内容 + 算 hash → `HistoryStore.Upsert`（去重或新插入 + 超限清理 + 图片落盘）。
4. 面板存活则刷新。全程无 UI 反馈（不打扰），status 可查。

### 5.2 面板主流程（成功直贴）

1. `Ctrl+Alt+V` → 面板 Show + 记录原前台句柄 + 焦点入搜索框。
2. 用户搜索/滚动 → 选中条目（文本摘要 / 图片缩略图）。
3. `Enter` → 写剪贴板 → Hide → 还原原窗 → 注入 Ctrl+V → 内容出现在原光标处。
4. 面板回隐藏常驻，监听继续。

### 5.3 异常路径

| 场景 | 行为 |
|------|------|
| 直贴注入失败（目标窗口消亡/拒绝） | 降级"仅复制"+气泡说明，面板已隐藏，用户手动 Ctrl+V 兜底 |
| 剪贴板写入竞争（他进程占用） | 重试 ≤3 次（W4 剪贴板竞争先例），仍失败气泡报错，禁静默 |
| 提权进程内容（UIPI） | 占位条目不含内容（FR-11③），首个此类条目时气泡一次性说明该已知局限 |
| 图片超限（>20MB） | 不入库 + 日志 Warn（一次性气泡提示阈值） |
| 库损坏 / 迁移失败 | 显式报错 + 备份旧库重建（P1a 原子写/损坏恢复同族纪律），禁静默清空 |
| 黑名单命中 | 静默丢弃（Debug 日志）；托盘"暂停捕获"开启时气泡确认状态，selfcheck 显示行 |

### 6.2 已拍板决策记录（D1~D4，2026-09-26 敲定）

| # | 决策点 | 结论 | 备注 |
|---|--------|------|------|

## 7. 实现步骤（Wave 5）

## 8. 注意事项与风险

| # | 风险 | 对策 |
|---|------|------|
| R1 | **UIPI 权限墙（★ 2026-09-28 修正措辞）**：UIPI 对剪贴板是**部分隔离** —— `GetClipboardData`/`EnumClipboardFormats` 只拦「跨 IL **且 非受信格式**」；`CF_TEXT(1)` / `CF_UNICODETEXT(13)` / `CF_BITMAP(2)` / `CF_DIB(8)` / `CF_DIBV5(17)` / `CF_OEMTEXT(7)` / `CF_PALETTE(9)` 在受信白名单（`HKLM\...\Policies\System\UIPI\Clipboard\ExceptionFormats`）里，**跨 IL 可读** ⇒ 提权进程复制**文本/图片**时托盘读得到（正常入库）；只有「owner 提权 + 内容**只以非受信（注册）格式**存在」才读不到（实测见 `踩坑全集.md` §2.32） | 降级占位条目（FR-11③）；不为此提权、不动 Core；**文档须写清白名单事实**——原措辞"非提权读不到提权内容"是绝对化错误，会让验收清单写出**永远无法通过**的用例。★ 副作用：原以为"提权内容天然不入库"的隐私效果对文本/图片**不存在**；若要"提权内容一律不收"，判据须改成 `OwnerElevated ⇒ 占位/跳过`（**待拍板**） |
