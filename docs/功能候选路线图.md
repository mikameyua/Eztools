## 1. 做什么（收敛后 3 件）

| # | 功能 | 复用底座 | 难度 | 一句话理由 |
|---|---|---|---|---|
| F1 | **屏幕取色** | W4 遮罩 + W5 剪贴板 | ★★ | 开发/写文档天天用；遮罩已能框选+读屏，闭环最顺 |
| F2 | **区域截图 → 剪贴板** | W4 遮罩 + W5 剪贴板 | ★ | 与 F1 **共用同一个遮罩窗实例**（capture/pick 模式切换），近乎白送 |
| F3 | **通用启动器 Launcher（W7）** | W3 搜索窗壳 | Wave 级 | 统一入口，用户感知最强；计算器/单位换算/编码转换全部作为它的 provider，**不独立立项** |

> **波次编号（2026-09-28 调整）**：视觉小波先做，占用 **W6**（`docs/W6-视觉小波-设计方案.md` 已落盘，待拍板 §8 D1~D6）；Launcher 顺延为 **W7**。

### F1 屏幕取色
- 要点：放大镜 loupe（放大预览 + 像素网格，这是主要 UI 工作量）；HEX / RGB / HSL 三格式；一键进剪贴板（复用 W5 PasteBack 通道）。

### F2 区域截图
- 要点：**只做"落剪贴板"**。多屏/混合 DPI 已被 W4-b 解决。
- 不做标注编辑器（箭头/马赛克等）——Snipaste 现成，自研无差异化。

### F3 Launcher（W7）
- 复用 W3 搜索窗**壳**（唤起 / 输入框 / nodes 渲染 / NativeInputBox 键盘链）；**查询引擎不复用**（USN/MFT 专用）。
- 新做 provider/action 抽象；首批 provider：文件（接 W3 引擎）、应用启动、计算器、单位换算、编码转换。
- 热键策略：Launcher 即主入口，其他工具尽量从它进入，缓解 RegisterHotKey 稀缺问题。

## 2. 明确不做（防止反复重提）

| 功能 | 理由 |
|---|---|
| 屏幕标尺 / 量角器 | 低频，用时开现成工具即可 |
| QR 码生成 | 偶发，手机/浏览器自带 |
| hosts 切换 | 频率配不上特权层复杂度（core 协议要加写文件白名单，暴露面不小）；SwitchHosts 现成 |
| 启动项管理 | 同上；PowerToys 现成 |
| 截图标注编辑器 | Snipaste 现成，高成本低差异化 |
| 截图翻译 / 表格转 Excel | 高成本低频；W4 OCR 提字已够用 |
| 键盘重映射 / 全局文本替换 | **永久排除**：键盘链 §2.25~§2.30 刚以"换实现"收口，不得再碰 |

## 3. 优先序

1. **视觉小波**：F1 取色 + F2 截图（一个遮罩窗、两种模式，一起做一起验收）。
