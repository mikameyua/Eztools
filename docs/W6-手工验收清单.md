## 1. 已自动化覆盖面（不必手测，列在这里防止重复劳动）

| 功能点 | 自动化载体（verify-desktop.py 断言） |
|---|---|
| 热键唤出（Ctrl+Alt+X / C → 遮罩 → Esc 收窗） | `--probe-capture-hotkey` / `--probe-pick-hotkey`（真键注入） |
| 截图端到端：真拖拽 → 位图进剪贴板 | `--probe-capture-overlay`（尺寸对账 ±1 + **内容五点抽样 == 自绘纯色窗定义值**） |

| `ezt config` 读写 capture.hotkey / pick.hotkey / color.format | acceptance 既有 config 闭环模式 |

## 2. 手工项（无法自动化的部分）

### M1 双屏混合缩放真机目测（条件依赖：物理第二块屏）

- **为什么还留人工**：探针已验证摆放对账（±8px）与取色/截图正确性，但"人眼看到的内容与坐标是否一致"最终观感只能在真双屏 + 不同缩放（如 175% + 100%）下确认。当前开发机单屏 ⇒ **本项 N/A**（有第二块屏时执行）。
- **判据**：副屏上框选/取色，得到的内容就是副屏该位置的内容（不偏移到主屏）；尺寸标签与实际相符。

### M2 主观 UX 手感（loupe / 气泡 / 流畅度 —— 无客观判据）

- **为什么无法自动化**：loupe 跟手度、放大倍率观感、色值字号、气泡文案可读性、"快进快出"手感是主观判断（F6 式手测）。
- **判据（通过标准）**：loupe 跟手无明显滞后；单击后气泡文案正确（"已复制 #rrggbb" / "已复制 W×H（位图，可直接 Ctrl+V）"）；Esc/右键退出即时；连做 10 次无卡顿/无残留遮罩。
- **命令**：同 M1 的 `--capture-show` / `--pick-show`（真托盘运行时也可直接按 Ctrl+Alt+X / Ctrl+Alt+C）。
- ⚠️ **show 模式须知（2026-09-30 修正后）**：
  - show 模式**不创建托盘图标**（设计使然）——三角区没有图标属预期；复制反馈改由**临时通知气泡**承担，复制成功后 ~1.8s 自动退出；
  - show 模式已修复"后台启动抢不到焦点 ⇒ Esc 失效"（§2.24①，用户双屏实测踩中）：唤出后强制把键盘前台让给遮罩，Esc/右键可正常退出；
  - **日常使用请直接双击 `Eztools.Desktop.exe`（不带参数）**——托盘图标在 Win11 默认折叠进任务栏右下角 **^ 溢出区**，把它拖到任务栏即可常驻显示；气泡同样走该图标。

### M3 真托盘形态下的完整循环（单实例 + 常驻形态冒烟）

- **为什么无法全自动**：真托盘常驻形态下连做"唤出 → 用 → 再唤出 → 设置窗口改热键 → 立即生效"的完整用户旅程，涉及真实焦点切换与手工输入；自动化已分段钉住（改热键生效链 = `--probe-host-settings`，唤出 = 热键探针），串联观感留人工。
- **判据**：设置窗口改 capture.hotkey/pick.hotkey → 保存 → 新热键立即生效、旧热键失效；改 color.format → 下次取色剪贴板格式跟随。

```bash

cd "D:/01-项目代码/Eztools" && DOTNET_ROOT=D:/dotnet10 ./src/Eztools.Desktop/bin/Debug/net10.0-windows10.0.19041.0/Eztools.Desktop.exe
```

```powershell

& '.\src\Eztools.Desktop\bin\Debug\net10.0-windows10.0.19041.0\Eztools.Desktop.exe'
```
